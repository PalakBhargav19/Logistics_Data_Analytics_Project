# Week 3 – Exploratory Data Analysis & Visualization

## 📌 Project Overview

This task focuses on exploring logistics-related data using Python and identifying meaningful patterns through Exploratory Data Analysis (EDA) and data visualization.

The analysis uses the Olist Brazilian E-Commerce customer dataset to examine customer distribution across states and cities and to identify geographical patterns that can support logistics-related decision-making.

## 📊 Dataset

**Dataset:** Olist Brazilian E-Commerce Public Dataset

The analysis uses the cleaned customer dataset prepared during Week 2.

### Dataset Characteristics

- Total Records: 99,441
- Total Columns: 5
- Unique Cities: 4,119
- Unique States: 27

## 🔎 Exploratory Data Analysis

The following analyses were performed:

- Customer distribution by state
- Top 10 states by customer count
- Top 10 cities by customer count
- Customer percentage by state
- Regional analysis
- Interpretation of geographical customer patterns

## 📈 Visualizations

Multiple visualizations were created using Python and Matplotlib, including:

- Customer Distribution by State
- Top 10 Cities by Customer Count
- Top 10 States by Customer Percentage

These visualizations help identify areas with higher customer concentration and provide useful geographical insights for logistics analysis and planning.

## 💡 Key Insights

- The dataset contains customers from 27 states.
- São Paulo (SP) has the highest number of customers.
- The analysis shows that customer distribution is concentrated in certain states and cities.
- Geographical customer concentration can be useful for logistics planning, distribution analysis, and operational decision-making.
